# Contribute to Awesome RSI

[中文版](survey.zh.md)

- Target Repository: [Awesome RSI](https://github.com/Prism-Shadow/awesome-rsi)
- Survey Paper: [Survey on RSI Research](https://arxiv.org/abs/2610.14625)

## Contribution Workflow

1. **Read the Survey & Taxonomy**: Read our [RSI survey paper](https://arxiv.org/abs/2610.14625) and browse the [Awesome RSI](https://github.com/Prism-Shadow/awesome-rsi) repository to familiarize yourself with the existing taxonomy and entry format.
2. **Open an Issue & Claim in Comments (Optional)**: Open an Issue in [Awesome RSI Issues](https://github.com/Prism-Shadow/awesome-rsi/issues) and leave a comment to claim it (claiming is optional and primarily prevents duplicate effort when curating a batch of papers or updating taxonomy sections; for single paper additions you may also open a PR directly).
3. **Submit a PR**: Add the new or recategorized RSI paper entries following the repository format and open a Pull Request in [Awesome RSI](https://github.com/Prism-Shadow/awesome-rsi).
4. **Maintainer Review & Merge**: Wait for a maintainer to review the paper metadata and taxonomy placement, and merge the PR once approved.

## Format Examples

### 1. Issue Example

**Title**: `[Paper] Add <Short Name or Topic>: <Paper Title>`

```markdown
### Paper Information
- **Title**: <Full Paper Title>
- **Links**: <arXiv / Code Repository URL>
- **Proposed Category**: <Target section in Awesome RSI>
```

### 2. Issue Claim Comment Example (Optional)

```markdown
I would like to curate this paper (or batch of papers) and plan to submit a PR by YYYY-MM-DD.
```

### 3. PR Example

**Title**: `docs(papers): add <Short Name or Topic>`

```markdown
Closes #<issue-number>

### Summary
- Added "<Paper Title>" under `<Category Section>` (including paper link, date, and code repository)

### Checklist
- [x] Verified paper links, authors, and publication date
- [x] Entry formatting and taxonomy placement match Awesome RSI conventions
```
