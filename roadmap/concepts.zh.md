# 基本概念

[English](concepts.md)

为了帮助首次接触自进化（Recursive Self-Improvement, RSI）社区的研究者与开发者快速建立全局认知，本页梳理了社区路线图与标准文档中高频出现的核心概念：**Agent（智能体）**、**自进化（RSI）**、**Harness（智能体运行框架）**、**Harness 层与模型层自进化的区别**，以及 **Benchmark（评测基准）**。

## 什么是 Agent

**Agent（智能体）** 是以大语言模型（LLM）或具备多模态理解能力的基座模型为核心，能够**感知环境（Perception）**、**自主规划（Planning）**、**调用工具（Tool Use）**并借助**记忆机制（Memory）**在多步交互中自主完成复杂目标的系统。

与传统“单轮输入文本 → 单轮输出文本”的静态对话模型不同，Agent 运行在与真实或沙箱环境的闭环交互中：
1. **观察（Observation）**：读取任务指令、代码仓库、数据文件或环境状态。
2. **思考与规划（Reasoning & Planning）**：拆解长程目标、制定子任务步骤，并在遇到阻碍时调整策略。
3. **行动（Action）**：调用文件读写、终端命令执行、代码解释器、浏览器或外部 API 等工具对环境施加改变。
4. **反馈与纠错（Feedback & Self-Correction）**：根据测试输出、编译器报错或环境返回结果迭代修正，直至达成目标并交付可验证的产物。

## 什么是自进化（RSI）

**自进化（Self-Evolution）**，在学术界亦常被称为**递归自我改进（Recursive Self-Improvement, RSI）**，是指智能体系统在解决任务的过程中，能够基于自身的执行轨迹（Traces）与环境评估反馈（Feedback），**自主诊断能力短板并迭代更新自身配置或参数**，从而在后续任务中持续获得性能提升的机制。

一个标准的自进化闭环通常包含四个核心步骤：
- **前向执行（Forward Rollout）**：智能体在给定任务集上执行推理与工具调用，生成完整的交互轨迹（包含思考过程、工具调用序列与最终产物）。
- **评估与归因（Evaluation & Critique）**：验证器（Evaluator）对产物打分，诊断模块对成功经验或失败根因进行归因分析。
- **经验提炼与更新（Evolution / Update）**：进化算法根据归因信号更新智能体系统——既可以修改外围的提示词、技能库与工具代码（Harness 层进化），也可以更新底层模型的参数权重（模型层进化）。
- **验证与保留（Verification & Selection）**：在验证集上检验更新后的系统，保留带来正向增益的演化分支，进入下一代（Generation）迭代。

## 什么是 Harness

如果将底层大模型（Foundation Model）比作智能体的“大脑”或“引擎”，**Harness（智能体底座/运行框架）** 就是包裹在模型外围、将裸模型转化为可靠工程智能体的**完整运行时架构与控制层**（例如社区重点建设的 [PenguinHarness](https://penguin.ooo/)）。

一个现代化的 Agent Harness 通常由以下可演化的核心组件构成：
- **系统指令与行为规约（Instructions / Prompts）**：如 `AGENTS.md`，定义智能体的角色边界、工作流准则与停止条件。
- **模块化技能库（Skills）**：如 `skills/<skill_name>/SKILL.md` 及其配套脚本，封装特定领域的标准操作规程（SOP）、领域知识与校验工具，按需挂载到上下文。
- **工具与执行沙箱（Tools & Sandbox）**：连接模型与物理数字世界的接口，包括文件操作、Shell 终端、浏览器自动化与 MCP 服务。
- **记忆与上下文管理（Memory & Context）**：负责跨会话经验持久化（长期记忆）、长程轨迹压缩（Compaction）与注意力分配。
- **多智能体编排与钩子（Orchestration & Hooks）**：支持主智能体向子智能体（Subagents）派发并行子任务，以及在工具调用前后注入自动化检查钩子。

## Harness 层自进化与模型层自进化的区别

根据自进化过程中**被更新的目标对象不同**，自进化研究可以分为 **Harness 层自进化（Harness-Level Self-Evolution）** 与 **模型层自进化（Model-Level Self-Evolution）** 两大范式。

- **Harness 层自进化**：保持底层大模型的参数权重冻结（Frozen Weights），通过搜索、重写、合成和修剪外围 Harness 组件（系统提示词、Skills 技能包、工具代码、记忆库、多智能体工作流）来实现能力跃迁。
- **模型层自进化**：直接优化底层大模型本身的参数权重（Model Weights），通过将高分执行轨迹蒸馏回模型（SFT）或在可验证奖励信号驱动下开展强化学习（RLVR / Agentic RL），将外部探索出的经验内化为模型的直觉能力。

两者的核心差异与互补关系如下表所示：

| 对比维度 | Harness 层自进化（第一阶段重点） | 模型层自进化（第二阶段扩展） |
| :--- | :--- | :--- |
| **进化对象** | 外围组件：提示词（`AGENTS.md`）、技能（`SKILL.md`）、工具脚本、记忆库、工作流拓扑 | 底层模型：神经网络参数权重（全量参数或 LoRA 适配器） |
| **核心机制** | 元提示优化（Meta-Prompting）、技能合成与修剪、代码演化、经验反思与检索 | 轨迹合成与蒸馏（Trajectory Distillation）、监督微调（SFT）、智能体强化学习（Agentic RL） |
| **GPU 与算力门槛** | **极低**：仅需模型推理（API 调用或轻量本地推理），无需梯度反传与大规模 GPU 集群 | **较高**：需要多卡 GPU 集群进行长上下文前向采样、梯度计算与参数更新 |
| **实验成本与迭代速度** | **低成本、分钟/小时级迭代**：单次进化仅消耗少量推理 Token，适合快速探索与复现 | **高成本、天/周级迭代**：涉及海量 Rollout 采样与训练步数，试错周期长 |
| **可解释性与可控性** | **高**：进化产物为人类可读的 Markdown 技能、提示词或代码，易于审计、编辑与回滚 | **黑盒**：能力编码在稠密浮点数权重中，难以局部手工修正或精确定位回退 |
| **跨模型迁移性** | **强**：进化出的优质 Skills 和工作流可直接迁移挂载到不同基座模型上生效 | **绑定特定模型**：训练得到的权重仅作用于当前基座模型，更换基座需重新训练 |
| **两者的协同关系** | 作为外层探索器，低成本探索任务解法并沉淀高质量轨迹（Traces）与技能资产 | 作为内层巩固器，将 Harness 探索出的显式经验内化进模型权重，抬升基座能力上限 |

这也是社区在[演进路线图](README.zh.md)中采取**两阶段策略**的原因：先通过低门槛、高透明度的 **Harness 层自进化** 汇聚社区算法与高质量进化轨迹，再水到渠成地迈向 **模型层自进化** 与 **Harness × 模型协同进化**。

## 什么是 Benchmark

在自进化研究中，**Benchmark（评测基准）** 不仅是一组静态的测试题，更是驱动智能体进化与客观度量泛化能力的**标准化任务环境与判分体系**（详细规范参见 [RFC-0001 Benchmark](../rfcs/RFC-0001-benchmark.zh.md)）。

一个标准的 RSI Benchmark 包含三大核心要素：
1. **任务用例（Cases）**：每个 Case 提供独立的初始工作区文件（`input_dir`）与明确的任务指令（`Prompt`），涵盖软件工程、数据分析、科研探索、企业办公等真实长程场景。
2. **独立验证器（Evaluator）**：严格与被测智能体隔离的自动化判分程序（校验脚本、单元测试或 LLM Judge），对智能体执行完毕后的工作区产物进行检验，并输出归一化的 `[0, 1]` 得分。
3. **面向自进化的防泄漏数据划分（Splits）**：
   - 传统评测通常只需要一个测试集；而自进化智能体需要在任务中学习与迭代。
   - 因此，RSI Benchmark 将同分布任务划分为**训练集（`train`，供算法在进化阶段交互与提炼经验）**、**验证集（`val`，供算法在进化过程中选优与防止过拟合）**以及**测试集（`test`，严格冻结、仅在最终评估时盲测一次以检验真实泛化能力）**。
   - 对于跨多领域的综合性基准（如 [GDPevo](https://arxiv.org/pdf/2608.03764)），还支持按任务族（Task Group）提供配对的子任务集（`*-train` 与 `*-test`），先在各任务族训练集上独立进化，再在对应测试集上评估泛化增益。

在社区生态中，**Benchmark** 提供标准赛场，**[Algorithm Plugin](../rfcs/RFC-0003-plugin.zh.md)** 提供与数据解耦的自进化算法插件，而 **[Evaluation](../rfcs/RFC-0002-evaluation.zh.md)** 则忠实记录智能体在进化前（`pre_evolution`）与进化后（`post_evolution`）的完整轨迹与得分对比，三者共同构成了可复现、可横向对比的开放 RSI 社区基石。
